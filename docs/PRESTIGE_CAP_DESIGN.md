# Prestige cap800・Deep MASTERY分離 — Issue #17 / speed-6

LOOP BREAKERは巨大数を増やしながらClear Timeの桁を削るゲーム。深部で停滞したらStage800でいつでもPrestigeしてFarmをやり直せるようにし、単純なPrestige回数では追加MASTERYを増やさない。HP曲線や他の成長式はspeed-5と同一。

## 採用仕様と境界

pは**完了済みPrestige数**。Cycle番号はp+1。次CycleのTargetは次のRequired Stage。

```text
requiredStage(p) = min(100 + 50 max(0,p−2), 800)
mastery(p<16)    = [1,.55,.36][min(2,p)] × .88^max(0,p−2)
mastery(p>=16)   = .36 × .88^(14 + deepMasteryLevel)
earned(highest)  = floor(max(0,highestClearedStage−800)/50)
Prestige確定時: deepMasteryLevel = max(existing,earned)
pendingDeepLevel = max(existing,earned)
next milestone  = 800 + 50 (pendingDeepLevel+1)
```

| 状態 | Required | 継続段数 | Deep0の倍率 |
|---|---:|---:|---:|
| P15開始 | 750 | 13 | .06832462 |
| P15で750攻略→Prestige→P16 | 800 | 14 | .06012567 |
| P16で800攻略→Prestige→P17 | 800 | 14 | .06012567 |
| P17以降Stage800即Prestige | 800 | 14 | .06012567 |

Stage799 CLEARではP16のPrestige不可、800/801 CLEARでは可能。Targetを825/850/900へ進めても必要Stageは800なので可否は維持される。現在のTarget CLEARを要求しない。Prestigeは明示操作のみ、最低時間制限なし。

Deep849→Lv0、850/899→Lv1、900→Lv2、950→Lv3。一度に950を攻略して確定すれば3Lv一括付与。CLEARした瞬間には倍率を変えず、確定後の次Cycleで適用する。同じ850を再攻略しても高水準記録は増えない。任意深化でP16より前に獲得しても記録は保存するが、旧MASTERY式を完全維持するためP16以降に倍率へ反映する。

## 比較方法

コード変更前にspeed-5の現行モデルを読んで、現行・capだけ・capと分離の3案を、次の3戦略でP0〜P50（51Cycle）比較した。初期2回のBREAK、購入/解禁/価格、HP/SOUL/恒久式は固定。通常購入は毎秒非ATK上限優先MAX→ATK、恒久購入は低Lv優先・SOUL実支払と繰越。

- Escape: 現在Required攻略後すぐPrestige。cap後はStage800のみ。
- +1 Deep: P16以降、前Cycleの最高milestoneの次を1つ攻略してPrestige。
- Deep Run: P16以降、前Cycleの最高milestoneから3つ先まで攻略してPrestige。

参照シミュレーションは停止予定深度をtarget_overrideに指定し、経路を順番どおり攻略する。実ゲームのTarget +25は攻略後にだけ行われる既存AUTO/手動を使う。モデルはその操作待ちをゼロとし、Stageスキップや自動Prestigeをproductionへ追加しない。旧案にはDeep報酬がないため、同じ深度比較のためだけに仮想の最高milestoneを保持する。

極端な旧案をP50まで実測するため、参照PythonではCLEARまで収入がなく購入もできない空の整数秒の判断だけを省略する。次CLEAR後最初の整数秒の購入に復帰し、購入頻度を早めない。通常計算17Cycleとの時間一致を1e-6秒以内で--check検証する。参照PythonはCLEARを列挙するが、本体にはその処理を持ち込まない。全9組の結果と各Cycle開始/終了Clear Time・恒久Lv・BURST再到達・Stage800到達・累積時間・次Reset予測は[機械出力](balance/issue-17-comparison.txt)。

## trade-offと長期の限界

P20でEscapeは3:11/90SOUL/28.28SOUL毎分、+1は7:37/136SOUL/17.86毎分、Deep Runは12:31/244SOUL/19.48毎分。Escapeが短時間リセットと早期効率、Deepが大きな1回報酬と次Cycleの圧縮を提供する。

P50ではEscapeは1:39/90SOUL/54.78毎分、+1は3:56/515SOUL/131.16毎分、Deep Runは6:22/1882SOUL/295.66毎分。Escapeは現在Cycleが最短、Deepは報酬・効率・将来倍率で優れる。P0〜P50累計はEscape約92.6分、+1約243.3分、Deep Run約275.7分。どちらかが全指標で優位にはならない。

Deep Runは任意の長期投資であり、P16の3milestone攻略は8:31、P17は13:52と長い。プレイヤーは途中のStage800攻略済みならいつでもPrestigeして撤退できる。105個の一意なDeep milestoneを獲得したP50後には、必要Stage800だけの次Resetは約1秒になる。これはStage800連打**だけ**による無料短縮とは異なり、Stage6050までの深部投資と恒久育成の結果。将来の超高速Escapeを一律に禁じる待機ゲートは追加しない。P50より先の無期限のテンポは未保証。
